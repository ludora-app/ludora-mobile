# Shared components catalog (`src/components/ui/*`)

Check here before building a new component: each entry gives purpose, real props and one real usage site. Props are copied from the source types; `path:line` is where to look.

Import paths vary because several folders have no `index.ts` (see "Import paths" at the bottom).

## Cards and list rows

- **`SessionCard`** (`ui/session-card/components/session-card.component.tsx:26`): session row card. Props: `item: SessionCollectionItemDto | FindOneSessionResponseData`, `isNextSession?: boolean` (default `false`, hides the top banner). Memoized. Use: `features/profil/components/profil-section/profil-section-5/profil-section-5-list/profil-section-5-list-item.component.tsx:16` -> `<SessionCard item={item} />`. Sibling `SessionCardSkeleton` takes `isNextSession?`; both exported from `@/components/ui/session-card`.
- **`FieldCard`** (`ui/field-card/components/field-card.component.tsx:24`): field card with image, address, distance. Props: `field: FieldResponseDto`, `showType?`, `showSport?`, `onPress?`, `sportImage?: SessionCollectionItemDtoSport`, `shadowVariant?: 'primary' | 'black' | 'secondary'` (default `'black'`); accepts `children` (rendered inside the card). Use: `features/my-fields/components/my-fields-list/my-field-card.component.tsx:50` (a `Chip` as child). `FieldCardSkeleton` takes `showSlots?: boolean` (`field-card-skeleton.component.tsx:5`).
- **`SessionTeamsCard`** (`ui/session-teams-card/session-teams-card.component.tsx:9`): two teams facing each other. Props: `session: FindOneSessionResponseData`, `disableSelection?`, `onSelectTeam?: (teamUid, side: 'left' | 'right') => void`, `selectedTeamUid?: string | null`, `userMeUid?: string | null`. Use: `features/session/components/session-section/session-section-teams/session-section-teams-card.component.tsx:51`.
- **`SportLevelCard`** (`ui/sport-level-card.component.tsx:11`): square tile to pick a sport and see its level. Props: `sport: SportProps`, `onPress: (sport) => void`, `level?: SportPreferenceResponseDataLevel`, `translationKey?` (default `'common.select_sport'`, a key). Use: `features/settings/components/settings-preferences/settings-preferences-sport/settings-preferences-sport-item.component.tsx:16`.
- **`QuickActionCard`** (`ui/quick-action-card.component.tsx:8`): tactile outlined action tile (icon + label) built on `ScalePressable`. Props: `label: string`, `iconName: TIconsAll`, `onPress?`, `variant?: 'vertical' | 'horizontal'` (default vertical), `isFlex?` (default `true`), `hasShadow?`, `iconColor?`, `className?`. Use as a `DialogConfirm` trigger: `features/profil/components/profil-header/profil-header-actions/profil-header-actions-block-user.component.tsx:45`.
