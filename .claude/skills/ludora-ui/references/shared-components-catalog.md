# Shared components catalog (`src/components/ui/*`)

Check here before building a new component: each entry gives purpose, real props and one real usage site. Props are copied from the source types; `path:line` is where to look.

Import paths vary because several folders have no `index.ts` (see "Import paths" at the bottom).

## Cards and list rows

- **`SessionCard`** (`ui/session-card/components/session-card.component.tsx`, design system "Carte de session" 9c): white card with the sport tile, `Sport · format` title, `organizer · level` subtitle, the organizer comes from `item.creator` (returned by every session collection and by the detail), a yellow seats pill (`Complet` when full), an orange fill bar, then date range and place. The whole card opens the session (or `onPress`). Props: `item: SessionCollectionItemDto | FindOneSessionResponseData`, `variant?: 'default' | 'suggestion'` (`default` = design system 9c with the fill bar, for home and lists; `suggestion` = 9b for the on-boarding: Baloo title, rose seats pill, orange icons, start time only, no fill bar; styles in `session-card.styles.ts`), `onPress?`, `className?`, `extraInfoRows?` (extra `SessionCardInfoRow`s under date and place, e.g. the team line of `on-boarding-sessions-joined-recap.component.tsx`), `hasJoinButton?` (integrated red "Rejoindre" button, `sm` in `default`, `md` in `suggestion`: joins without a team so the API picks it, tracks `session_joined` / `session_joined_failed`), `onJoinSuccess?: (data: JoinSessionResponseData) => void` (screen-specific follow-up, e.g. navigation). Memoized. Lists use `SESSION_CARD_LIST_ITEM_HEIGHT` (card without join button + gap) in `getFixedItemSize`. Use: `features/home/components/home-session-list/home-session-list.component.tsx` (`ItemComponent={SessionCard}`), `features/on-boarding/on-boarding-sessions/components/on-boarding-sessions-suggestions/on-boarding-sessions-suggestions-list.component.tsx` (`variant="suggestion" hasJoinButton onJoinSuccess`, in `on-boarding-sessions-suggestions-item.component.tsx`). `SessionCardSkeleton` mirrors it; both exported from `@/components/ui/session-card`.
- **`FieldCard`** (`ui/field-card/components/field-card.component.tsx:24`): field card with image, address, distance. Props: `field: FieldResponseDto`, `showType?`, `showSport?`, `onPress?`, `sportImage?: SessionCollectionItemDtoSport`, `shadowVariant?: 'primary' | 'black' | 'secondary'` (default `'black'`); accepts `children` (rendered inside the card). Use: `features/my-fields/components/my-fields-list/my-field-card.component.tsx:50` (a `Chip` as child). `FieldCardSkeleton` takes `showSlots?: boolean` (`field-card-skeleton.component.tsx:5`).
- **`SessionTeamsCard`** (`ui/session-teams-card/session-teams-card.component.tsx:9`): two teams facing each other. Props: `session: FindOneSessionResponseData`, `disableSelection?`, `onSelectTeam?: (teamUid, side: 'left' | 'right') => void`, `selectedTeamUid?: string | null`, `userMeUid?: string | null`. Use: `features/session/components/session-section/session-section-teams/session-section-teams-card.component.tsx:51`.
- **`SportLevelCard`** (`ui/sport-level-card.component.tsx:11`): square tile to pick a sport and see its level. Props: `sport: SportItem` (`@/types/sports.types`, from `useGetSports()`), `onPress: (sport) => void`, `level?: SportPreferenceResponseDataLevel`, `translationKey?` (default `'common.select_sport'`, a key). Use: `features/settings/components/settings-preferences/settings-preferences-sport/settings-preferences-sport-item.component.tsx:16`.
- **`QuickActionCard`** (`ui/quick-action-card.component.tsx:8`): tactile outlined action tile (icon + label) built on `ScalePressable`. Props: `label: string`, `iconName: TIconsAll`, `onPress?`, `variant?: 'vertical' | 'horizontal'` (default vertical), `isFlex?` (default `true`), `hasShadow?`, `iconColor?`, `className?`. Use as a `DialogConfirm` trigger: `features/profil/components/profil-header/profil-header-actions/profil-header-actions-block-user.component.tsx:45`.

## Headers and footers

- **`HeaderOutlined`** (`ui/navigation/header-outlined/header-outlined.component.tsx:9`): default header of new screens (outlined title + back button). Props: `title?`, `titleKey?` (translated inside; returns `null` when neither is given), `hasTopSafeArea?`, `hasHorizontalPadding?`, `showBackButton?` (default `true`), `rightContent?: ReactNode`, `px?`, `gap?`, `fontSize?` (28), `outlinedStringWidth?`, `className?`. Also exports `HEADER_OUTLINED_HEIGHT = 50` (used as `listHeaderComponentHeight`). Use: `features/settings/components/settings-header.component.tsx:11` (feature wrapper with `Pick<HeaderOutlinedProps, ...>`).
- **`HeaderRounded`** (`ui/header/components/header-rounded.component.tsx`, `import { HeaderRounded } from '@/components/ui/header'`): new-design white header with rounded bottom corners (`rounded-b-header`), warm shadow and top safe area. Title (`title-1`) centred on the screen: when `hasGoBack` or `rightContent` is set, both sides get a `size-11` slot. Props: `title`, `hasGoBack?`, `onGoBack?`, `rightContent?: ReactNode`, `className?`, `children` (rendered under the title row, e.g. a `ProgressStepper`). Use: `features/on-boarding/on-boarding-profile/components/on-boarding-header.component.tsx`. The rounded corners are transparent: give its parent the screen background (`bg-background`, e.g. `app/(root)/on-boarding/profile/_layout.tsx`), otherwise the default grey shows behind them.
- **`HeaderHero`** (`ui/header/components/header-hero.component.tsx`, `import { HeaderHero } from '@/components/ui/header'`): yellow header (`bg-tertiary`, `rounded-b-header`) with a big centred mascot on its halo, optionally a centred title and description. Props: `mascotName`, `mascotSize?` (`MascotHalo` size, default `'lg'`), `isMascotAnimated?`, `title?`, `description?`, `hasGoBackButton?` (default `true`; without it the top safe area gets an extra 16 px), `className?`. Use: `features/auth/register/screens/register-step-1.screen.tsx` (mascot only), `features/on-boarding/on-boarding-sessions/screens/on-boarding-sessions-joined.screen.tsx` (`md`, animated, title + description, no back button).
- **`HeaderMascot`** (`ui/header/components/header-mascot.component.tsx`, `import { HeaderMascot } from '@/components/ui/header'`): new-design yellow header (`bg-tertiary`, `rounded-b-header`, top safe area) with a title on the left and a mascot on the right. Props: `title`, `mascotName: TIconsAll`, `description?` (subtitle under the title), `hasGoBackButton?` (default `true`), `hasMascotHalo?` (renders the mascot through `MascotHalo size="sm"`), `mascotClassName?` (default `size-20`), `className?`. Use: `features/auth/login/screens/login.screen.tsx`, `features/on-boarding/on-boarding-sessions/screens/on-boarding-sessions-suggestions.screen.tsx` (with `description` and `hasMascotHalo`).
- **`HeaderScreen`** (`ui/header/components/header-screen.component.tsx:7`): big tab-screen header (outlined title, subtitle, mascot). Props: `title?`, `subTitle?`, `isTitleLoading?` (renders a `Skeleton`), `hasNewSession?`, `iconProps?`, `className?`, `leftContentClassName?`, `children`. Use: `features/home/components/home-session-list/home-session-list-headers/home-session-list-header-top-list.component.tsx:56`.
- **`HeaderGoBack`** (`ui/navigation/header-go-back/components/header-go-back.component.tsx:9`): back button + title row. Props: `title?`, `titleProps?: StringProps`, `iconName?: TIconsAll`, `hasTopSafeArea?`, `className?`. Use: `features/auth/register/screens/register-step-2.screen.tsx:74`. `GoBackButton` (`onPress?`, `className?`) is the bare round button.
- **`FooterWrapper`** (`ui/footer-wrapper/footer-wrapper.component.tsx:16`): sticky screen footer with a top shadow. Props: `hasBottomSafeArea?`, `shadowVariant?: 'black' | 'primary'`, `className?`, `onLayout?`. Use: `features/invite-friends/components/invite-friends-footer.component.tsx:65`, `features/create-session/components/create-session-footer/create-session-footer.component.tsx` (measures its height with `onLayout`). - **`FormSheetHeader` / `FormSheetFooter`**: see `formsheets-and-dialogs.md`.

- **`MascotHalo`** (`ui/mascot-halo/components/mascot-halo.component.tsx`, `import { MascotHalo } from '@/components/ui/mascot-halo'`): mascot icon on a light yellow disc (`bg-tertiaryHalo`), optionally floating (`isAnimated`, Reanimated loop).
